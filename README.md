I wanted to build this machine so I can make the future more sustainable in energy and perhaps help out if I can
This is a cool project for me and I have always been fascinated with solar panels
This allows me to take advantage of the sun and cut electricity bills for me
Features: dual axis tilt, allows the movement of up, down, left and right movement to track the sun, a OLED screen to show percentage of battery, tracking the sun, a output port that allows you to do charge things like your phone, 20 watt solar panel to get the electricity
